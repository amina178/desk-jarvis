# Desk Jarvis

CV assistant for the desk: hand-gesture shortcuts, posture monitoring and
blink-rate tracking from an ordinary webcam. Upload a short video recorded
at your desk (camera in front, shoulders in frame, sit upright for the first
seconds) to get a report, or try the live tab.

Code and training notebooks: see the GitHub repository.
